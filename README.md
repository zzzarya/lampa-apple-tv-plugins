**Мои торренты — плагин Lampa 1.4.0**

Файл: [my-torrents-1.4.js](my-torrents-1.4.js). Адрес локального TorrServer уже задан в `SERVER_URL`.
Раздачи добавляются через браузер, затем открываются в «Мои торренты» штатным вызовом плеера Lampa.
Jackett и собственный поиск раздач не нужны. Публичных/приватных ключей, токенов и внешних JS-зависимостей в плагине нет.

**Обновление на Apple TV**

1. Удалите прежнюю запись нашего плагина из списка расширений Lampa.
2. Добавьте [https://zzzarya.github.io/lampa-apple-tv-plugins/my-torrents-1.4.js](https://zzzarya.github.io/lampa-apple-tv-plugins/my-torrents-1.4.js).
3. Полностью закройте и снова запустите Lampa MX. Путь с новой версией позволяет обойти старый кэш.
4. Откройте **Мои торренты** в боковом меню либо **Настройки → Мои торренты → Открыть мои торренты**.

`my-torrents.js` и `my-torrents-1.4.js` содержат одну актуальную версию; устанавливать нужно только один. Файлы 1.1, 1.2 и 1.3 оставлены для возврата к прежней версии.

**Карточка фильма или сериала**

1. Откройте раздачу. Внизу списка сезонов или файлов выберите **Выбрать карточку фильма или сериала**.
2. Нажмите **Найти: …** либо **Ввести другое название**. Поиск выполняется через каталог Lampa; язык зависит от её настроек.
3. Выберите нужный фильм или сериал по названию и году. Первый результат автоматически не выбирается.
4. Привязка сохраняется локально по хешу раздачи. При следующем открытии выбирать карточку заново не нужно.
5. Чтобы заменить или убрать привязку, откройте **Карточка: …**, выберите другой результат либо **Снять привязку**.

Если в данных TorrServer уже есть `data.lampa.movie`, плагин использует эту карточку автоматически. Такую привязку тоже можно заменить или отключить. В сохранённых при разработке данных она есть у «Лэндмен», а у Ted Lasso её нет.

Для сериала названия запрашиваются через `Lampa.Api.seasons` и сопоставляются по **номеру сезона и серии**. Например, в интерфейсе и плейлисте будет «2 серия — Название эпизода». Для фильма с одним видео используется название карточки. Исходные пути и таймкоды не меняются.

Если в каталоге нет указанного сезона/эпизода или каталог не ответил за 15 секунд, сохраняются подписи из файлов. Нумерация торрента должна соответствовать каталогу: переименование сезона и сдвиг номеров автоматически не выполняются. Для сборных файлов с несколькими эпизодами сохраняется подпись диапазона. Для серии без известного сезона название из каталога не угадывается.

Используются API каталога самой Lampa, без добавления ключей в JS. Их наличие и доступность сети в Lampa MX нужно проверить на устройстве. При отсутствии API поиска/хранилища пункт привязки не показывается; доступные API видны в диагностике плагина.

**Прогресс подготовки видео**

При выборе видео плагин запускает предзагрузку выбранного файла в MatriX.137 и показывает процент заполнения стартового буфера, скорость и число пиров через `Lampa.Loading`. Если такого API нет, используется окно с полосой прогресса и кнопкой отмены.

Процент берётся из `preloaded_bytes / preload_size`, как в Lampa, и относится к буферу TorrServer. Это не процент скачивания всего фильма и не измерение готовности декодера tvOS. Статистика буфера относится к раздаче на сервере; при параллельном просмотре она может включать уже закэшированные данные. Начальный запрос предзагрузки может блокироваться, поэтому статистика опрашивается отдельными запросами раз в секунду.

После достижения 95% либо успешного завершения предзагрузки сервером открывается плеер. При отключённой предзагрузке видео тоже запускается. **Назад** отменяет ожидание и возвращает к файлам; запоздалый ответ не запускает отменённое видео. Отмена закрывает экран и прекращает опрос, но не удаляет и не останавливает всю раздачу на сервере.

Через две минуты ожидания либо при ошибке доступны **Повторить**, **Открыть без ожидания** и **Назад**. Ошибка сама по себе не запускает видео. Экран показывается при запуске из плагина; во время переключения серий внутри нативного tvOS-плеера загрузкой управляет сам плеер.

**Файлы, сезоны и плейлист**

Расширение и технические метки вроде `2160p.WEB-DL.H.265` убираются. Распознаются `S01E02`, `1x02`, «1 серия», «Серия 1», папки `Season 1`, «Сезон 1», «1 сезон» и номера внутри указанного сезона. При привязанном сериале доступный `Lampa.Torserver.parse` дополняет разбор, например для `S0102`. Отсутствующий сезон не подменяется штатным значением 1.

В «Мои торренты» сначала выбирается сезон. Плеер получает **все видео раздачи**, отсортированные по сезонам и номерам серий, с отдельными URL и таймкодами. Плейлист содержит подписи «Сезон 1 · 2 серия — Название» и поля `season`, `episode`. Отдельные группы сезонов внутри окна tvOS Universal зависят от приложения и не подтверждены.

Исходный путь остаётся в подписи файла. Назад возвращает к сезонам, затем к раздачам и меню. Обновление списка перечитывает TorrServer. Плагин не добавляет и не удаляет раздачи; открытие файлов/предзагрузка могут активировать раздачу для получения данных.

**Продолжение просмотра**

В **Настройки → Плеер → Тайм-код** выберите **Продолжить** или **Спрашивать**, если пункт доступен в вашей сборке. Позиции обрабатывает `Lampa.Timeline`; идентификаторы из 1.2.0 сохранены. Привязка карточки, изменение подписи или IP TorrServer не сбрасывают их.

Для проверки посмотрите минуту, выйдите кнопкой Назад и откройте тот же файл. Рядом должна появиться «Позиция …». Повторите после перезапуска приложения. Очистка данных приложения удаляет локальные привязки и таймкоды. Принудительное закрытие во время просмотра может не дать плееру записать последнюю позицию.

**Проверки и ограничения**

Пройдены 42 теста: запуск и меню, сеть, плейлист, сезоны, таймкоды, экран загрузки и отмена, ошибки/таймауты, привязка карточки и названия серий. Использовались настоящие модули Lampa `Reguest`, меню, плейлист, Timeline, Loading, MediaLoading, Api и Torserver/EpisodeParser. Ответы каталога/TorrServer и нативное воспроизведение имитировались. В тестах также используется сохранённый ответ MatriX.137 с десятью сериями Ted Lasso.

Пользователь подтвердил появление пункта и открытие файла на Lampa MX 0.2 (build 610); на снимке выбран «Встроенный tvOS Universal». **Новые возможности 1.4.0 ещё нужно проверить на приставке.**

При проблемах откройте **Настройки → Мои торренты → Диагностика 1.4.0**. `MYTS-NET`/`MYTS-HTTP` относятся к доступу к серверу; `MYTS-PRELOAD` — к подготовке буфера; `MYTS-CARD`/`MYTS-CATALOG` — к привязке/каталогу; `MYTS-TIMELINE` — к отсутствующему API таймкодов. Политика доступа к локальной сети, кодеки и поведение нативного плеера определяются сборкой приложения.

**HTTPS-хостинг**

Репозиторий: [zzzarya/lampa-apple-tv-plugins](https://github.com/zzzarya/lampa-apple-tv-plugins).
Файлы находятся в корне ветки `main`. В **Settings → Pages** используется **Deploy from a branch → main → / (root)**.
Адрес выше должен возвращать JavaScript с комментарием `My Torrents 1.4.0` по HTTPS, без входа и страницы GitHub. MIME-тип — `application/javascript` или `text/javascript`. GitHub описывает [публикацию Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) и [HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https).

Если IP изменится, исправьте `SERVER_URL`, опубликуйте файл с новым путём/меткой версии и перезапустите приложение. Публичный доступ к TorrServer для хостинга JS не нужен.
