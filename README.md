**Мои торренты — плагин Lampa 1.3.0**

Файл: [my-torrents-1.3.js](my-torrents-1.3.js). Адрес уже задан.
Путь: боковое меню → «Мои торренты» → раздача → видеофайл → штатный вызов плеера Lampa.
Сторонние библиотеки, поиск и Jackett не нужны.

В версии 1.3.0 добавлены читаемые названия, выбор сезона и полный плейлист раздачи. Удаляются расширение и технический хвост вроде `2160p.WEB-DL.H.265`; распознаются `S01E02`, `1x02`, «1 серия», «Серия 1», папки `Season 1`, «Сезон 1», «1 сезон» и номера файлов внутри явно указанного сезона. Серии сортируются по номеру, сезоны — по номеру; сезон 0 показывается как «Спецвыпуски». Если сезон не указан однозначно, он не придумывается.

Примеры: `Название фильма.1080p.WEB-DL.mkv` → «Название фильма»; `Show.S01E02.Название серии.1080p.mkv` → «2 серия — Название серии». Если в файле нет названия серии, показывается только её номер. Перевод названий и получение названий серий из внешнего каталога не выполняются; новые зависимости, аккаунты и ключи не нужны. Исходный путь остаётся в подписи файла и используется без изменений для воспроизведения и таймкода.

При запуске выбранной серии плеер получает **все видеофайлы этой раздачи**, включая остальные сезоны, в правильном порядке. Каждая запись содержит собственные URL, таймкод, номер сезона и номер серии, если они распознаны. В «Мои торренты» сначала выбирается сезон. Штатному плееру передаётся плоский список с подписями «Сезон 1 · 2 серия — Название»; наличие отдельных вкладок или групп сезонов внутри нативного окна tvOS Universal зависит от приложения и не подтверждено. Добавленных заголовков без видео в плейлисте нет.

Сохранён механизм таймкодов из 1.2.0 через `Lampa.Timeline`. Идентификатор по хешу раздачи и полному пути файла не меняется при смене названий в интерфейсе или IP TorrServer. В списке файлов сохранённое время отображается как «Позиция 13:21».

Пройдены 28 тестов, включая разбор названий, сезоны и порядок серий, полный плейлист, запуск выбранной серии, переход через границу сезона, прежние таймкоды и защиту подписей от HTML. Использовались настоящие JS-модули Lampa, включая её плейлист; события видео и нативный плеер имитировались. На сохранённом ответе MatriX.137 с Ted Lasso проверены 10 серий сезона 4. По сообщению пользователя, на Lampa MX 0.2 (build 610) версия 1.1.0 добавляет пункт и открывает файл. **Новые возможности 1.3.0 ещё нужно проверить на приставке с «Встроенный tvOS Universal».**

**Обновление до 1.3.0**

Удалите прежнюю запись плагина и добавьте новый адрес:
[https://zzzarya.github.io/lampa-apple-tv-plugins/my-torrents-1.3.js](https://zzzarya.github.io/lampa-apple-tv-plugins/my-torrents-1.3.js).
Полностью закройте и снова запустите Lampa MX. Новый путь файла позволяет отличить 1.3.0 от старой копии в кэше. Если боковой пункт отсутствует, проверьте **Настройки → Мои торренты → Диагностика 1.3.0**.

**Проверка названий и плейлиста**

1. Откройте раздачу с несколькими сезонами. Выберите сезон, затем любую серию, кроме первой.
2. Проверьте, что запущена выбранная серия, а в плейлисте есть все видео раздачи, в порядке сезонов и серий.
3. Переключите серию через плейлист или «Следующая». Автопереход после окончания зависит от настройки Lampa «Следующая серия» и её поддержки вашим плеером.
4. Если имя распознано неверно, сообщите исходный путь из подписи файла и ожидаемое название. Нумерация и названия берутся только из имён файлов и папок; точность произвольных схем именования не гарантируется.

**Проверка продолжения просмотра**

1. В **Настройки → Плеер → Тайм-код** выберите **Продолжить** или **Спрашивать**. Названия подтверждены по исходникам Lampa; расположение в вашей сборке может отличаться. Плагин эту настройку не меняет.
2. Откройте файл через «Мои торренты», посмотрите минимум минуту и выйдите обычной кнопкой **Назад**.
3. Снова откройте ту же раздачу: рядом с файлом должна появиться «Позиция …». Запустите его и проверьте продолжение с сохранённого места.
4. Повторите после обычного перезапуска Lampa. Позиции хранит Lampa в своём профиле; очистка данных приложения удаляет локальные записи.

Таймкоды, записанные версией 1.2.0, продолжают использоваться. Для файлов без таймкода он появится после просмотра. Если в списке не появилась позиция, передача прогресса из tvOS Universal ещё не подтверждена; сообщите этот результат. Если позиция есть, а запуск идёт с начала, сообщите её значение и выбранный режим «Тайм-код». Плагин использует штатные правила продолжения Lampa, включая её обработку почти досмотренного видео. Принудительное закрытие приложения во время просмотра может не дать плееру записать последнюю позицию.

**HTTPS-хостинг: GitHub Pages**

1. Репозиторий: [zzzarya/lampa-apple-tv-plugins](https://github.com/zzzarya/lampa-apple-tv-plugins). Актуальные файлы `my-torrents.js` и `my-torrents-1.3.js` содержат 1.3.0; устанавливать нужно только один. `my-torrents-1.1.js` и `my-torrents-1.2.js` оставлены как предыдущие версии.
2. Откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch**. Выберите `main` и `/ (root)`, сохраните.
3. После успешной публикации адрес плагина: [https://zzzarya.github.io/lampa-apple-tv-plugins/my-torrents-1.3.js](https://zzzarya.github.io/lampa-apple-tv-plugins/my-torrents-1.3.js).
4. Откройте адрес на Mac: он должен отдавать JavaScript, начинающийся с комментария `My Torrents 1.3.0`, без страницы GitHub, входа в аккаунт или ошибки 404. Для своего хостинга нужны HTTPS с доверенным сертификатом и MIME-тип `application/javascript` либо `text/javascript`.

GitHub описывает [публикацию Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) и [HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https). Публикация изменений может занять до десяти минут.

**Установка на Apple TV**

1. В Lampa откройте настройки плагинов/расширений; название пункта зависит от сборки.
2. Отключите прежний неработающий `my_ts.js`, добавьте HTTPS-адрес нового файла и полностью перезапустите Lampa.
3. Откройте боковое меню → **Мои торренты** либо **Настройки → Мои торренты → Открыть мои торренты**. Выберите раздачу, затем видеофайл. Первое получение метаданных может занять до минуты.
4. Плагин вызывает `Lampa.Player.play()` и использует выбранный в Lampa плеер. Если требуется встроенный плеер приложения, выберите его в настройках Lampa; на вашем снимке выбран «Встроенный tvOS Universal». Настройки TorrServer в Lampa плагин не меняет.

Кнопка **Назад** возвращает из списка файлов к сезонам (если они распознаны), затем к раздачам и меню. **Обновить список** перечитывает сервер. Раздачи добавляйте прежним способом через браузер. Плагин не добавляет и не удаляет раздачи. При открытии файлов сервер может активировать раздачу для получения метаданных.

**Если не работает**

| Признак | Что проверить |
| --- | --- |
| Красный значок, раздел не появился | Сначала проверьте HTTPS-адрес файла и перезапуск. По одному значку нельзя установить причину сбоя прежнего плагина. |
| `MYTS-JS 1.3.0` | Код новой версии начал выполняться. Если сообщения нет, ещё не подтверждён запуск JS; проверьте новый адрес и полный перезапуск. |
| `MYTS-MENU 1.3.0` | Пункт добавлен. Ищите «Мои торренты» в боковом меню; также доступен запасной вход через настройки. |
| `MYTS-HIDDEN 1.3.0` | Редактор меню скрывает пункт. Включите его через редактирование меню либо используйте вход через настройки. |
| `MYTS-INIT`, `MYTS-SETTINGS`, `MYTS-API` | Откройте диагностику в настройках плагина и сообщите её текст. Поля показывают наличие API и меню в этой сборке. |
| `MYTS-TIMELINE` | В сборке недоступен API таймкодов. Видео запускается без обещания сохранения позиции. |
| `MYTS-NET` | Доступ Apple TV к локальной сети и HTTP-серверу. CORS вашего TorrServer проверен; политика HTTP/mixed content внутри TestFlight-сборки не проверена. HTTPS-хостинг JS сам по себе не снимает эти ограничения. |
| `MYTS-HTTP 401` | Сервер требует авторизацию; отдельной формы логина в плагине нет. |
| `MYTS-TIMEOUT`, `MYTS-FILES` | Повторите запрос; проверьте, получила ли раздача метаданные в веб-интерфейсе TorrServer. |
| Файлы видны, видео не играет | Проверяйте выбранный плеер, контейнер и кодеки на tvOS. Успешное воспроизведение в VLC на Mac этого не гарантирует. Плагин не перекодирует видео. |

Если сборка блокирует локальный HTTP, потребуется разрешённый ею способ доступа к серверу или локальный HTTPS с доверенным сертификатом. Простая замена `http` на `https` без настройки TLS не поможет. Публичный доступ к TorrServer для хостинга плагина не нужен.

**Использованные API**

Плейлист передаётся через [штатный API плеера](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/player/playlist.js). Сохранение позиции повторяет передачу `timeline` и `playlist` в [штатном торрент-компоненте Lampa](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/torrent.js), с [хранилищем таймкодов](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/timeline.js) и [логикой сохранения/продолжения](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/player/timeline.js).

- [TorrServer MatriX.137: `/torrents`](https://github.com/YouROK/TorrServer/blob/MatriX.137/server/web/api/torrents.go): JSON POST `{"action":"list"}`.
- [TorrServer MatriX.137: `/stream`](https://github.com/YouROK/TorrServer/blob/MatriX.137/server/web/api/stream.go): GET `?link=<hash>&stat`, затем `/stream/<имя>?link=<hash>&index=<file.id>&play`. Индекс берётся из ответа сервера; файлы отбираются по расширению, что не является проверкой кодеков.
- [Lampa: меню](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/menu/menu.js), [редактор меню](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/menu/editor.js), [настройки](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/settings/api.js), [окна выбора](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/select.js), [сеть](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/utils/reguest.js), [плеер](https://github.com/yumata/lampa-source/blob/7a53473aa5d75793e5b80fb2edbb862c4440c79c/src/interaction/player.js). Используются встроенные в Lampa jQuery, `Reguest.native`, `Select`, `Controller`, `Timeline.view`, `Player.play`; `Player.playlist`, если доступен, получает весь отсортированный список видео раздачи. Таймкоды обрабатывает Lampa; её существующие настройки профиля и синхронизации не меняются. Обращений к сторонним API нет.

Если IP изменится, исправьте `SERVER_URL` в начале JS, загрузите файл заново и переустановите ссылку с новой меткой, например `?v=2`, затем полностью перезапустите приложение.
